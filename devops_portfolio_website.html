// my story

From Mainframe to Cloud

2022 — The Beginning
Started as a Mainframe Developer
Joined as a Mainframe developer — writing COBOL, working with JCL, batch processing. Loved the discipline of enterprise-grade systems. But kept wondering: what's out there in the cloud world?
COBOLJCLBatch Processing
2023 — The Spark
Discovered DevOps & Cloud
Stumbled upon a YouTube video about Kubernetes. One video became ten. Ten became a hundred. I opened an AWS free tier account at 11pm on a weeknight. I haven't stopped since.
AWS Free TierYouTube LearningLinux Basics
2023–2024 — Building the Foundation
Self-Teaching Everything from Scratch
No bootcamp. No mentor. Just documentation, hands-on labs, and a lot of broken Terraform plans. Learned Linux deeply, Docker fundamentals, and started building AWS infra with Terraform.
DockerTerraformAWS EC2/S3/VPCBash
2024 — Going Deeper
Kubernetes, CI/CD, and Real Projects
Started building actual projects — not just following tutorials. Set up my own EKS cluster, wrote CI/CD pipelines from scratch with GitHub Actions, deployed real apps end-to-end. Started this portfolio.
KubernetesGitHub ActionsEKSHelm
2025 — Now
Ready to Make the Switch
Portfolio built. Skills sharp. Hunger high. Actively looking for DevOps / Cloud roles where I can bring my mainframe discipline + cloud enthusiasm. The journey doesn't stop — it accelerates.
